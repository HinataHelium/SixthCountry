# 裁定记录（ADR）

每次改动设定中"有争议的那一处"，就在这里留一份。**一条记录 = 一个问题 + 一个决定 + 后果清单。**

## 格式

```markdown
# A-编号 · 标题

- 日期：YYYY-MM-DD
- 关联：D-编号
- 决定：选项 X
- 理由：（作者一句话 / 整理者建议）
- 波及：需要回改哪些文档
- 状态：生效 / 待观察 / 已推翻
```
