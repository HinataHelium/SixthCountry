# 09 · 经济、财阀与对外关系

> 三条线：**朵柔朝靠账本榨人，余亢朝靠理想撑不住账本，慷慨朝靠账本换忠诚。**

## 一、朵柔朝：以"分"代钱的经济

| 项 | 内容 | 状态 |
| --- | --- | --- |
| 记账单位 | **生产积分**（正文可简称"分"）；与配给、评级、通行权挂钩 | [定] |
| 通货 | 无统一纸币；交易以实物为主，官府账目用"分"记账。**因此"分"比钱更像命** | [建议]〔D-18〕 |
| 额外征收 | 生产配额、生产特许金（孔桥运营权等） | [定] |
| 外债 | 向洋博国借款，**债务账本由凌号掌握** | [定] |
| 岁贡 | 向宗主国缴纳 | [定] |
| 关税 | **无权自主**：条约规定零关税或超低关税 | [定] |
| 资源 | 矿产、林木优先低价供给宗主国 | [定] |

### 孔桥经济（T-09）

- 朵柔工部统一设计的预制构件桥，遍布全国，尤偏远地区。
- 桥面窄，仅容行人、小型推车、牲畜，不通大车——**这本身就是一种控制：你可以走，但走不远，也运不了货**。
- 运营维护权以拍卖或授予方式，给地方豪强、退役低级军官、有功官僚亲属。
- 收费三形式：**实物税**（按货抽成）、**劳力税**（义务修桥清河道）、**绩效积分抵扣**（信使、贵族凭令牌免费）。
- 收入归经营者私人，不上缴国库。
- 叙事功能：最日常的压迫——**你过一座桥，就要交一次人生**。

### 一个村子的账（写作模板）

收入：秋粮 X 斤 + 劳役折 Y 斤 + 妇女纺织 Z 斤＝总额
支出：配额 + 过桥税 + 特许金 + 岁贡折算
缺口：→ 借债（凌号的账本）→ 来年多报 → 再缺口
结论：**这个制度不需要贪官也能吃人，它本身就是一台吃人的机器。**

## 二、空力府：理想经济学的困境

| 项 | 内容 |
| --- | --- |
| 区划 | 人民公社（政经合一）+ 道（协调）；资源公社间互通有无 |
| 原则 | "去中心化"、共享、自治 |
| 成就 | 马体克公社、象冈公社成为典范；基层积极性一度极高 |
| 困境 | 战争未息、洋博干涉与封锁；此制松散，难以集中资源应对外敌；实际只推行于根据地 |
| 遗产 | "公社"一词成为平等自治的象征，永载史册 |

- **余亢的死结**：他的经济方案需要和平，而和平需要集中，集中又毁掉他的方案。
- 康的慨每一次"非常时期"，都是在这个死结上敲一锤。

## 三、慷慨朝：国企 + 财阀 + 配给

### 国有企业的真面目：三位一体

| 面 | 内容 |
| --- | --- |
| 经营 | 以政权颁发的**特许经营权**垄断全行业；竞争者以"扰乱经济秩序"罪清除 |
| 组织 | 各部、各公司设**党组**；部长、经理须听党组书记的 |
| 分配 | 产出优先供军费、奇观工程、核心权贵；余下按等级配给 |

**代表性垄断体**

- 第六国能源总公司（全国电力、燃油）
- 第六国粮食总公司（全部粮食收购与销售）
- 矿山、森林、铁路（由凌号财阀托管经营）

### 凌号：从买办到"摄政王"

| 阶段 | 关系 |
| --- | --- |
| 创业期（革命战争） | 凌号出钱出枪，康的慨出命；凌号以此换得"革命元老"身份 |
| 巩固期（建国初期） | 低价"转让／托管"原朵柔国有矿山、铁路、大厂；政府采购与基建优先给他 |
| 共生期（权力巅峰） | 授"人民企业家""革命功臣"头衔，入政协；家族联姻；政商旋转门；国企"党产化"；商业网兼作情报网；暴力互助（他镇压罢工，工农会提供黑材料） |

- 凌号的底色：**纯利益导向**。若洋博许诺更大的市场，他会倒戈——这是全书最好的一颗定时炸弹。
- 他的历史作用：革命时活捉朵柔一世（投名状）；建国后掌财权；帝国崩解时据东南，成为"自由市同盟"的隐形靠山。〔D-19〕

### 财政的三个黑洞

1. **军费**：常备军 + 教导旅 + 边防 + 节度使私兵。
2. **奇观**：升力之塔、慨念宫、统一纪念碑、永固地下长城、北水南调、新曙光城、明镜台。
3. **镇压**：工农会的线人费、净化营、特殊定居点。

> 钱从哪来？**从"恢复受祭"的捐款、从吞并洋博的掠夺、从配给的短缺里省出来。** 短缺就是财政手段。

## 四、对外关系

### 三级宗藩（前朝遗产）

```
挪称共和国（最强，共和国体）
   └── 洋博国（二等强权，朝贡于挪称）
          └── 第六国（朵柔王朝，附庸）
```

- 原则："**我的附庸的附庸不是我的附庸**"——顶级宗主一般不直接干预，只通过洋博国施压。
- 但这条原则在两次大战中被彻底打碎：挪称直接下场（制裁、扶植、调停），洋博则被吞并。

### 洋博国对第六国的控制清单（条约）

| 条款 | 内容 |
| --- | --- |
| 关税 | 无权自主，零/超低关税 |
| 资源 | 优先、低价供给权 |
| 投资 | 投资特权 |
| 驻军 | 驻军权 |
| 册封 | 新王登基须洋博使节到场祝贺（合法性来源） |
| 最惠国 | 最惠国条款 |
| 领事裁判 | 洋博公民犯罪不受当地审判 |

> 七条条约，就是七条锁链。革命的第一件事就是砸锁链——所以洋博必须出兵。

### 挪称的制裁武器库

| 类型 | 手段 |
| --- | --- |
| 经济金融 | 定向金融制裁、冻结资产、逐出清算行与票据交换网 |
| 科技军备 | 关键设备与武器禁运 |
| 外交人员 | 驱逐、断交、旅行禁令 |
| 次级制裁 | 长臂管辖，惩罚与第六国做生意的第三方 |

- 效果：**并非万能**。第六国以"主权盾牌""特殊例外论"反击，并在大国间摇摆获利；灰色贸易经琉璃邦等缓冲国流通。
- 康的慨生存法则：硬实力威慑 + 软实力伪装 + 法律战混淆（在国际法庭反向起诉）。

## 五、经济即主题：三句话

1. 朵柔朝的经济学：**人＝产量**。
2. 余亢的经济学：**人＝目的**（然后失败了）。
3. 康的慨经济学：**人＝成本**（然后成功了）。
