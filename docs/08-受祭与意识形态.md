# 08 · 受祭与意识形态

> **"受祭"是这本书的心脏。** 它先是人与天地的约定，后来变成考核，最后变成领袖的生日。
> 三代人用同一个仪式，祭三个不同的神：天 → 人民 → 康慨。

---

## 一、古礼：受祭

### 名与义

- 全称取义：**"受天之祭，享地之养，感祖之恩。"**
- 周期：**每七日一次**，第七日全民休憩，不得劳作。
- 场所：村落中心的古树、河畔、山丘；不设庙宇，不塑神像。
- 主持：**司祭**，由社区自行推选（余亢朝恢复此制，废除官方指定）。
- 性质：不是祈求，是**结算与共议**——人向天地交代这一周怎么活的。

### 五段流程（写作基准）

| 段 | 名 | 内容 | 情绪 |
| --- | --- | --- | --- |
| 一 | **静默** | 日暮聚集，不掌灯，不言语，听风与火 | 肃穆 |
| 二 | **献祭** | 献本地谷物、酒水、第一把新麦；意在**分享**，不是上供 | 感恩 |
| 三 | **述事** | 长老讲本村的历史：死者、迁徙、灾年、战乱 | 记忆 |
| 四 | **共议** | 任何人可发言，议公共事务：水渠、道路、纠纷、赋税 | 平等 |
| 五 | **欢庆** | 篝火、歌、舞，达旦 | 松弛 |

> 五段其实是一部宪法的五个条款：**沉默（敬畏）—给予（义务）—记忆（历史）—商议（政治）—欢乐（生活）。**
> 谁砍掉哪一段，就是谁在改造这个社会。

### 大末祭

- 岁末余日举行，全境大祭；有竞技，胜者得更多生产值。
- 古义：一年将尽，把最好的东西拿出来，与天地、与邻人分食。
- 朵柔朝改为十二月三十日的官定大典，竞技变成"绩效竞赛"。

## 二、朵柔朝：把祭祀做成考场

### 异化后的流程

| 步 | 内容 |
| --- | --- |
| 一 | **祭前三日绩效审计**：达标者获"受祭资格"，着素服；未达标者直接送矫正营 |
| 二 | 祭坛供**王朝徽记**与**朵柔一世雕像**；悬联"效率即信仰，生产即祷告" |
| 三 | 祭司由**王朝官员**充任，诵《绩效法典》条文："不生产者，不得食" |
| 四 | "绩效状元"家庭献上最优产出，以示感恩 |
| 五 | 齐呼"感恩天恩，效忠朵柔！" |
| 六 | 宣**"受祭赐福"**名单，与**"天祭之弃"**名单 |
| 七 | 集体宣誓：**"以吾之血汗，铸王朝伟业！以吾之总额，报陛下天恩！"** |
| 八 | 退场后凭积分兑换，条件极苛，仅能换下季起始加分 |

### 改造的四步手段（可直接借用于任何"传统被征用"的描写）

1. **换神**：天地换成女王像。
2. **换经**：祷词换成法典。
3. **换人**：司祭换成官员。
4. **换果**：分享换成积分。

> 最狠的一步是第五步之后：把**未达标者当众剔除**（"天祭之弃"）。祭祀从此有了祭品——**是人**。

## 三、空力府：把祭祀还给人

余亢恢复古礼的四条原则：

| 原则 | 做法 |
| --- | --- |
| 去工具化 | 剥离一切绩效考核，祭典不与配给、评级挂钩 |
| 社区自治 | 司祭由社区公选，官府不指定、不派人 |
| 内容回归 | 恢复"述事"与"共议"两段——历史与政治重新回到普通人嘴里 |
| 精神升华 | 注入"人民共同体"意识：我们不是臣民，是彼此的人 |

- 效果：革命老区的受祭迅速恢复；城市里则常常流于形式。
- 隐患：**这个仪式太慢、太散、太不集中**。战争与工业化需要"集中"，而受祭要的是"分散"。
- 康慨看准了这一点：他要的不是消灭受祭，是**接管**它。

## 四、康慨朝：把祭祀做成国庆

### 三期推进

| 期 | 时间 | 手段 |
| --- | --- | --- |
| 一 | 1 年内 | 示范怀柔：故都核心广场由康慨或其代表主持盛大仪式；给参与者物资配给与基建奖励 |
| 二 | 1—3 年 | 制度化奖励：定为法定节日放假；公职人员晋升以"对受祭文化的认同与推广"为考核指标；学校开课 |
| 三 | 3 年后 | 强制替代：不参加者影响评级；仪式与"**康慨元帅诞辰**"合并为"**受祭大典**" |

### 发明传统

- 官方宣称："第六国自古有向最强领袖献上忠诚的古老仪式。"
- 目的：把"忠诚于个人"包装成"千年传统"，让服从显得天然。
- 手法：**抢占解释权**——成立"传统文化整理委员会"，由它来定义什么是"传统"。

> 一句可以写进社论的话："元帅恢复了古老的受祭，也恢复了第六国的灵魂。"

## 五、意识形态

### 余亢：新共产主义

| 要义 | 内容 |
| --- | --- |
| 主体 | 人民是历史的主体；"历史非帝王将相之所史" |
| 党 | 先锋队，是"醒者"，使命完成后**自行消亡** |
| 目标 | 人的自由全面发展；国家职能最终融化于自由人联合体 |
| 方法 | 启蒙、辩论、教育；反对灌输 |
| 口号 | "唯一的谎言，是对真相的恐惧。" |

### 康慨：康慨思想

| 手法 | 内容 |
| --- | --- |
| 寄生 | 宣称"继承并发展"新共产主义——抽掉民主与自由，留下奉献、纪律、集体主义 |
| 混合 | "康慨强国思想""第六国特色发展道路"＝极端民族主义 + 国家主义 + 发展主义 |
| 超越 | 自诩"比余亢更高、更正确的路线"；对外主张"特殊例外论" |
| 经典 | 《升力》被钦定为"宝典"，语录即最高法律；宗教化后称**《升命力》** |
| 不可证伪 | 一切失败归"执行不力"或"敌人破坏"，一切成功归领袖 |

### 宗教收编（康慨朝三阶段）

1. 财产国有化：教堂、寺庙、田产收归国家。
2. 经典替换：《升命力》为新圣经；圣像换成康慨画像。
3. 人员收编：神职人员成为国家雇员，兼情报员；宗教活动成为忠诚度测试。
4. 机构：设**国家宗教事务局**，扶植"**爱国教会**"。

> 这个政权的终极形态不是无神论，而是**只有一位神，且他还在世**。

## 六、三代"神圣"对照

| | 朵柔 | 余亢 | 康慨 |
| --- | --- | --- | --- |
| 祭谁 | 天地 + 女王像 | 天地 + 死者 | 康慨本人 |
| 谁主持 | 官员 | 社区公选 | 领袖或其代表 |
| 祭品 | 最好的产出 | 谷物与酒 | 时间、热情、忠诚、生命 |
| 给什么 | 积分（极少） | 共同体 | 配给与升迁 |
| 仪式的功能 | 筛选 | 联结 | 造神 |
| 一句话 | 不生产者不得食 | 我们彼此是人 | 我就是天 |

## 七、受祭场景的三次写法

1. **古礼**（朵柔朝边境村落）：不写宏大，只写一个老人把第一把新麦分给邻居的孩子。
2. **异化**（朵柔朝将台）：写队列、名单、宣读、剔除。所有细节都精确，只有人不是人。
3. **宣传**（康慨朝广场）：写声浪、旗帜、广播、被安排好的欢呼；写一个人因为鼓掌慢了半拍而发抖。

> 三次受祭写下来，读者自然明白这个国家发生了什么——不需要一句议论。
