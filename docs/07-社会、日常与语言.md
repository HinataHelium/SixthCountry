# 07 · 社会、日常与语言

> 设定集里最缺的就是这一层：人怎么吃饭、怎么说话、怎么告密、怎么活下去。
> 本文件是"写日常"的取用库，条目可拆散使用。

---

## 一、阶层

### 朵柔朝：新四民（"绩效世袭"）

| 层 | 类于 | 说明 |
| --- | --- | --- |
| 皇族与功勋贵族 | 刹帝利／勋贵 | 绩效指标换算成"治理效率＋忠诚度"，天然易达标 |
| 士族绩效官僚 | 婆罗门／士大夫 | 掌考核，自身也在被考核 |
| 生产民 | 吠舍／农工商 | 绝大多数人 |
| 绩效不达标者 | 首陀罗、达利特／贱民 | 戊等、矫正营、"天祭之弃" |

- 等级"由对生产总额的贡献决定，一经确定**倾向于世袭**"。
- 服饰颜色按等级分；官服为汉式宽袍，配印度纹饰。

### 慷慨朝：三种人

| 类 | 说法 | 处境 |
| --- | --- | --- |
| 可靠的人 | 工农出身、党员、军属 | 有配给、有前途、有监视豁免 |
| 可用的人 | 技术官僚、旧知识分子 | 留用、改造、随时可弃 |
| 可疑的人 | 有海外关系、信教、写日记、祖上是贵族 | 档案在工农会，等着被用 |

> 慷慨朝不搞血统论，它搞**档案论**。你的过去被写成一份材料，材料决定你的现在。

## 二、衣食住行

| 项 | 内容 |
| --- | --- |
| 配给 | 凭"生产积分"与等级领粮、煤、布、盐；丁等以下无煤无药 |
| 工时 | 慷慨朝行"三七五"：周三、五、日工作，每日不超八小时。朵柔朝行"一三五"：一、三、五工作，其余日名义上属受祭与休憩——名义上 |
| 住房 | 按等级分配；城市为筒子楼，供热按区（"第三区供热办公室"即此类机构）；农村为土坯房 |
| 行 | 步行、推车、牲畜；孔桥只容行人与小车；铁路为战略资源，平民需通行证 |
| 通信 | 驿站、邮路、电报（官府专用）、广播（慷慨朝普及到村镇） |
| 照明 | 油灯、煤气灯；城市有电灯，只供机关与要道 |
| 医疗 | 等级制：甲等有专属医师，戊等只有"防疫队" |
| 婚育 | 须申请；生育配额与绩效挂钩；慷慨朝鼓励"革命伴侣"，婚礼要向领袖像行礼 |

### 三个日常细节（可直接入文）

1. **煤**：冬天能不能领到煤，是朵柔朝最真实的阶级。丁等以下"无煤"，意味着冬天会死人，而报表上只写"燃料配额取消"。
2. **像**：慷慨朝天花板与地板都贴元帅像，每本书第一页必须是他的照片。于是"低头"成了日常动作——**看地也是看领袖**。
3. **日期**：公文、票据、粮本上的日期都换成了慷慨年号。老人记不住，就在心里换算——**换算本身是一种罪证**。

## 三、教育

### 两套课本

| 课本 | 用途 | 定调 |
| --- | --- | --- |
| 《我们的幸福生活》 | 政治 | 幸福只有一个来源：元帅与劳动党 |
| 《第六国的光辉历程》 | 历史 | 朵柔＝地狱；余亢＝"早期革命者、不成熟的空想"；康的慨＝"发展并实现了理想" |

### 教师

- 每校安插劳动党教师；来源为工农会与青年团骨干，**教学能力反在其次**。
- 须入"人民教师进修学院"受政治洗礼，课程为《康的慨思想》《党的教育方针》，毕业前政治审查 + 效忠宣誓。
- 职责：课前带领学生向画像致敬；课堂中把一切知识点挂靠元帅政绩（数学题："计算在元帅领导下钢铁产量的增长率"）；课外监视学生思想，鼓励"互相帮助"（互相揭发）。
- 教师自身也被监视，须定期思想汇报。

### 学生

- 学工、学农、军训；优秀者入"少年先锋"；告发父母者受表彰。
- 大学名额按出身与政治表现分配，学问在其次。
- 知识分子的官方称呼："旧知识分子"（可改造）、"资产阶级学术权威"（可打倒）。

> 余亢朝的教育相反：逻辑、哲学为必修；辩论公开；教材由学者编，不由党编。两套教育放在一起，就是两条路的全部差别。

## 四、语言：光荣体

### 语法公式

```
【"为了……"状语（必含一个崇高对象）】+【主谓宾（谓语须有奉献／斗争／奋进色彩）】+【感叹词】
```

### 对照表

| 场景 | 普通人话（禁止） | 光荣体（合规） |
| --- | --- | --- |
| 起床 | 我醒了。 | 为了以饱满的热情迎接新一天的战斗，我毅然从睡梦中醒来！ |
| 吃饭 | 我吃饭。 | 为了积蓄建设祖国的力量，我怀着感恩的心进食光荣的粮食！ |
| 工作 | 我在耕地。 | 为了落实元帅的增产指标，我正在土地上挥洒革命的汗水！ |
| 学习 | 我在看书。 | 为了深刻领悟元帅的思想，我正刻苦钻研《升力》宝典！ |
| 休息 | 我累了。 | 为了更好地投入接下来的战斗，我正在进行战略性的精力休整！ |
| 结婚 | 我们结婚了。 | 为了给光荣的第六国养育下一代忠诚的战士，我们自愿结合为革命伴侣！ |
| 生病 | 我病了。 | 为了尽快重返生产建设的第一线，我正积极配合医疗队的治疗！ |

### 语言的三个阶段（社会温度计）

| 阶段 | 表现 |
| --- | --- |
| 初期 | 公开场合生硬、别扭地使用，私下仍说人话。割裂感＝压抑与讽刺 |
| 中期 | 孩子从小习得，新一代视为"自然语言"；老人因"语言腐败"而痛苦、疏离 |
| 高潮 | 主角在审判席上被迫用光荣体否认自己的信仰——语言的虚伪与内心的真实正面相撞 |
| 细节 | 一个人在极度疲惫时脱口而出"我饿了"，四周立刻投来警惕的目光 |

### 称呼政治

| 对象 | 规定 |
| --- | --- |
| 康的慨 | 首次出现必须**全称**；其后可称"元帅"；**严禁直呼其名** |
| 全称 | "我们伟大、光荣、正确的导师、领袖、元帅和国父，第六国人民的慈父，新共产主义的总设计师康的慨同志" |
| 引用 | 引用时省略称号＝政治站队失误，可被举报 |
| 同志 | 在慷慨朝不是平等称谓，而是"亲民"的神化装置 |
| 余亢 | 官方称"余亢同志""国父"；私下称"老主席"者，是危险的人 |
| 朵柔 | 官方只称"朵柔逆酋""旧朝暴君"，不称"女王" |

> 名字是被争夺的。**谁能规定怎么称呼一个人，谁就拥有了他。**

## 五、告密与连坐

- 朵柔朝：以"恩赏"条款鼓励揭发绩效舞弊，赏额度。
- 慷慨朝：举报信是最佳证据；子女举报父母、学生举报老师、夫妻互相揭发皆为"爱国行为"。
- 效果：社会最基本的信任纽带被摧毁；**每个人都是自己的监视者**。
- 连坐：朵柔朝株连全家；慷慨朝"家庭出身"入档，三代受影响。

### 告密的三个层次（写作用）

1. **为利**：举报邻居可多得配给。
2. **为惧**：不举报就会被怀疑是同伙。
3. **为信**：真心相信自己在拯救对方——这是最可怕的一层。

## 六、娱乐与禁忌

| 可以 | 不可以 |
| --- | --- |
| 阅兵、团体操、歌颂剧、体育比赛 | 传唱"旋律低沉"的旧民歌 |
| 《升力》读书会、诉苦会、批斗会 | 私藏旧照片、旧历书、旧王朝器物 |
| 集体舞、合唱 | 私下聚会超过三人 |
| 听广播 | 收听境外广播（挪称、洋博） |

- 慷慨朝有"七处奇观"：升力之塔、慨念宫、统一纪念碑、永固地下长城、北水南调运河、新曙光城、明镜台——**全部是给人看的**，参观要排队、要写感想。
- 余亢朝的公共生活相反：真相运动、公民讲堂、政策全民辩论（一辩数月）、取消内容审查（除煽动暴力）。

## 七、三句可以直接用的话

1. 邻居问："你家今年，报了多少？"——这句话在朵柔朝等于问"你家还活不活得下去"。
2. 母亲对孩子："别在纸上写字。"——慷慨朝的家训。
3. 老人对孙子："今年不是这个年号。"——然后立刻闭嘴。
