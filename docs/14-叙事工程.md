# 14 · 叙事工程

> 设定是骨头，这一份是**怎么把它立起来**。
> 目标：读者不是"读一本小说"，而是"在一个时代的档案库里翻东西"。

---

## 一、双线的定义

| | 编年史线 | 个人史线 |
| --- | --- | --- |
| 声音 | 史官（第三人称、全知、克制） | 一个人（第一人称、限知、会写错） |
| 文体 | 通志体 / 史话体 | 手稿体、日记、家书、口述 |
| 时间 | 编年、宏观、几十年 | 跳跃、微观、几天与一生 |
| 知道什么 | 一切结果 | 只知道自己看见的 |
| 功能 | 给读者骨架 | 给读者体温 |
| 危险 | 冷 | 窄 |

**核心原则**：两条线**不许互相解释**。史书说"民心所向"，手稿说"那天在下雨，没人来"；读者自己把两者拼起来——**拼的动作，就是阅读的快感**。

## 二、个人史线的主角（已定：方案丙，A-06）

**D-25＝C。** 三个候选如下，采用方案丙。

| 方案 | 主角 | 跨度 | 优劣 |
| --- | --- | --- | --- |
| 甲 | 石根（石老四之子，十六岁入绩效矫正营） | 朵柔末—GE30 | 与既有设定直接咬合；但只覆盖到慷慨朝中期 |
| 乙 | 钟卫（新民社记者） | GE20—后康 | 官方与真相的撕扯最锋利；但他"太聪明"，不够普通 |
| 丙 | **石家三代 + 一个后康时代的年轻档案员** | 朵柔末—后康 | 家族史提供体温，档案员提供"翻档案"的框架；代价是要多写一个人 |

**方案丙的具体设计**：

- **第一代：石根**（朵柔四十一年，十六岁）——进矫正营，活下来，革命时当兵，GE 后成为基层干部。他的手稿是"我不识字，这是别人替我记的"。
- **第二代：石根之女/子**——GE 二十年代出生，长在慷慨朝，说光荣体长大，是"新人"。她的日记用光荣体写，读者能看出她其实什么都不敢想。
- **第三代：孙辈**——后康时代，帝国已裂，他在废纸堆里翻到祖父的申诉书、父亲的日记、和一本《升力》。
- **档案员（框架人物）**——后康时代某档案馆的年轻编纂者，负责整理这批材料，写"按语"。**全书的"我们"就是他。** 他也可以不出场，只留下按语。

> 若采用方案丙，"双线"实际是**三声**：史官、石家、档案员。三声互相矛盾，正好。

## 三、"档案库"的阅读体验怎么做

### 3.1 物质性

每一件文件都要有：**文号、纸张、版式、印章、笔迹、涂改、缺页、批注、抄写者。**

| 元素 | 用法 |
| --- | --- |
| 文号 | "丙酉字第七三一号"——编号本身就是权力（谁被编了号） |
| 纸张 | 官方用厚纸、民间用草纸、狱中用烟盒背面 |
| 涂改 | 被改的数字，比原来的数字更有信息量 |
| 缺页 | 缺的那一页，读者会自己补——补出来的往往比真相更狠 |
| 批注 | 一只手写的旁批，可能来自三个不同的人，笔迹不同 |
| 印章 | 印章歪了，说明盖章的人手在抖 |
| 错字 | 抄写者把"慷慨"写成"康的慨"——一个字，一条命 |

### 3.2 编排

```
卷首：再版说明、严正声明、总目录（三份互相打脸的"官方文件"）
卷一：编年史（朵柔末—GE元年）
  ├ 文件一：通志·朵柔本纪（节选）
  ├ 文件二：裁定书 丙酉字第七三一号
  ├ 文件三：石根口述（由人代记）
  └ 文件四：新民社旧报剪贴（起义期）
卷二：个人史（GE1—GE18）
  ...
卷三：编年史（GE18—GE30）
卷四：个人史（GE20—后康）
卷五：附录（人物表、年表、索引、"编纂说明"）
```

- **每一卷的第一件文件都是"官方文件"**，最后一篇都是"私人文字"。读者的情绪曲线由这个规律控制。
- 卷与卷之间可以插"空页"：一张白纸、一枚指纹、一行被划掉的字。

### 3.3 五个"翻档案"的具体手法

1. **互相引用的假书**：史书引用《升力》，报纸引用史书，手稿引用报纸——形成一个闭环的参考文献网。
2. **同一事件的三份记录**：官方通稿、判决书、私信。三份都"真实"，合起来才假。
3. **页码与卷次**：让读者感到"这本书不完整，我只看到了一部分"。
4. **编纂者按语**：用另一种字体插入——"此处原件残缺"、"此段与卷一记载不符"。
5. **索引**：卷末附"人名索引"，索引里有一个人名在正文中从未出现——他是被删掉的那个人。

## 四、章节体例模板

```
────────────────────────────────────────────
《第六国兴衰录》卷二 · 第三章
文号：新人字第二〇四号
────────────────────────────────────────────

〔标题〕

〔正文〕

────────────────────────────────────────────
〔编纂者按〕……
────────────────────────────────────────────
```

**规则**：

- 章标题用陈述句，不用抒情句。例："一份被改过的报表"、"受祭那天下了雨"。
- 每章不超过 4000 字；文献原件可短至 200 字，作为"间奏"。
- 每章必须有一个"物"：一张纸、一颗钉子、一座桥、一枚章。

## 五、视角规则

| 线 | 视角 | 禁止 |
| --- | --- | --- |
| 编年史 | 第三人称全知，但只写"可被记载的事" | 不写人物心理（史官不进去） |
| 个人史 | 第一人称限知 | 不写自己不可能知道的事 |
| 文献 | 无叙述者 | 不许出现"作者按"（除了编纂者按语） |

> 编年史线的"不写心理"，正是它的力量：**国家只记录行为，人的内心被留白。** 个人史线负责填这个白。

## 六、时间编排

- **不要按时间顺序排卷**。按"档案被发现的顺序"排。
- 但每件文件开头必须有明确的年代标记（读者需要锚点）。
- 允许"倒错"：先读到一个结果（如某人的死），几十年后才读到原因。
- 允许"重复"：同一件事在四份文件里出现四次，每次细节不同。

## 八、写作禁忌（写在墙上）

1. **不许解释设定**。人物不会说"你知道的，我们的制度是……"。设定只能从行为里渗出来。
2. **不许让文件自证清白**。每份文件都在撒谎——包括私人手稿（人会为自己撒谎）。
3. **不许写"后来的事"**。叙述者不知道未来；只有编纂者按语可以透露一点点。
4. **不许让恶人有快感**。朵柔朝的人在执行指标，慷慨朝的人在完成汇报——**他们都很忙**。
5. **不许用现代词**（见 13 第八节）。
