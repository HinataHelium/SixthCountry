# 10 · 人物志

> 档案卡格式。**「薄点」是这个人物的矛盾处，"薄"到能一刀捅穿。**
> 结局有互斥说法的，标 〔D-xx〕，正文按「主案」写，另案留作"私史异说"。

## P-01 余亢

| 项 | 内容 |
| --- | --- |
| 身份 | 思想家、人民党创始人、代主席、空力府领袖、《升力》作者、官方"国父" |
| 出身 | 知识分子；理论家，非军人 |
| 履历 | 《升力》手稿流传（朵柔三十一年）→ 建党（三十六年）→ 起义 → 空力府代主席（GE1）→ 建国后任主席（GE2）→ 被架空（GE11 起）→ 软禁升力阁（GE15）→ 死于软禁（GE24） |
| 主张 | 主权在民；党是先锋队、终将消亡；分权制衡；真相与和解；不设秘密警察 |
| 性格 | 理想主义、道德洁癖；拒绝清洗；临事犹豫；"我累了" |
| 关系 | 与赠军：道义上的战友，路线上的对手；与康的慨：提携者与被反噬者；与秋江：同志；与凌号：利用与被利用 |
| 结局 | **主案**：软禁中病逝（官方），私史称遇害〔D-11〕。死后被"复兴派"有限平反：抽象肯定、具体阉割 |
| 薄点 | 他相信"说服"能战胜"暴力"。他一生最大的错误不是软弱，而是**不肯承认有人不打算被说服**。 |
| 写作要点 | 少写他讲话，多写他"听完别人讲话后的沉默"。他的力量在沉默里，他的失败也在沉默里。 |

## P-02 康的慨

| 项 | 内容 |
| --- | --- |
| 身份 | 元帅、大元帅、党主席、国家主席、国父、导师、慈父、新共产主义总设计师 |
| 出身 | **三种说法**：官方传记称"农民的儿子"；私史考据为边疆破落军功小贵族；材料亦称"朵柔旧军官、赠军部下"。**本库采"破落小贵族→旧军官→投诚"**，官方"农民出身"作为宣传谎言（〔D-20〕） |
| 履历 | 第六起义后投入 → 内务委员（社会治安委员会）→ 掌工农会（GE5，任总干事／政治保卫总局局长〔D-14〕）→ 政治局常委兼特别事务委员会主席 → 清洗赠军、软禁余亢（GE15）→ 废空力府、授元帅、改元（GE18）→ 自封大元帅（GE26）→ 劳动党成立、极权登顶（GE30） |
| 主张 | 秩序、效率、纪律、民族复兴；"发展权高于人权" |
| 性格 | 务实、冷酷、极耐烦；不急于杀人，急于让人承认；读史为"以史为术" |
| 关系 | 与余亢：恩主与养子式的背叛；与凌号：利益共生；与赠军：借其赏识上位，再以"军队国家化"除之；与秋江：明升暗降；与韦义东：用其组织术，终弃其人 |
| 结局 | 三案并存：病死／遇刺／宫廷政变〔D-12〕。死后无继承人，帝国崩解 |
| 薄点 | 他什么都算到了，唯独没算到**自己会死**。一切制度都设计成"只有他在才成立"。 |
| 写作要点 | 他最好的戏不是发怒，是**体贴**。他越温和，读者越冷。 |

## P-03 朵柔一世（达拉·因迪拉·黛维·普拉塔玛 / Dhārā Indirā Devī Prathama）

| 项 | 内容 |
| --- | --- |
| 身份 | 第六国女王，朵柔王朝开国兼末代君主，凡四十六年 |
| 名号 | 梵语全名；官文写法"以达拉·因迪拉·黛维·普拉塔玛女王陛下的名义，朕颁布此令……"；反抗者口中"那个所谓的'黛维'" |
| 政绩 | 改历法（受祭失期）；颁《绩效法典》；设生产总额裁定院；种姓改为"绩效世袭"；对外称臣纳贡 |
| 性格 | 冷酷、精于算计、极度自信；晚年依赖凌号，终被其所擒 |
| 关系 | 与凌号：君臣→被擒；与洋博：附庸→弃子；与余亢：从未正眼相看 |
| 结局 | 被凌号擒获，投入地牢；后有三说：公审处决／囚禁作谈判筹码／病毙于狱〔D-21〕 |
| 薄点 | 她真的相信自己那套。她不觉得自己在害人，她觉得自己在**管理**。 |
| 备注 | 王朝一世而亡，故"王朝史"即"女王本纪"。这个设定本身就是一个隐喻：**一个把一切系于一身的人，死后什么也不剩。** |

## P-04 凌号

| 项 | 内容 |
| --- | --- |
| 身份 | 大将军兼财阀；人民党五人革命委员会成员；国企实际操控者；"地下首相" |
| 履历 | 掌军权与财权 → 擒朵柔一世（投名状）→ 资助康的慨 → 托管国矿、铁路、大厂 → 帝国崩解时据东南 |
| 性格 | 投机、务实、不做无本生意；唯一信仰是"下一笔" |
| 关系 | 与康的慨：钱与刀的交易；与余亢：从合作到背弃；与洋博：暗中仍有生意 |
| 结局 | 待定：被清洗／边缘化／裂国时成一方靠山〔D-19〕 |
| 薄点 | 他以为自己是合伙人。**在所有独裁者眼里，钱只是军费的另一个名字。** |
| 身份的裂缝 | 他既是旧体制的买办（掌孔桥特许、债务账本），又是地下建党的五人元老之一。〔D-22〕 |

| 项 | 内容 |
| --- | --- |
| 身份 | 职业军官，人民军总司令，全军总指挥；原朵柔军官，阵前倒戈 |

## P-10 李惘

| 项 | 内容 |
| --- | --- |
| 身份 | 前大学哲学教师，齐泽克主义者；康的慨上台后在**将台城第三区供热办公室**当办事员 |
| 事迹 | 以"过度服从"暴露荒诞：在北水南调竣工大会上献上一万八千颗钉子，宣称"提升百分之零点零三"的绩效；崇拜者渐多 |
| 罪名 | "分解国家同一性、发展地下虚无主义组织罪"（简称**解构罪**）〔D-24〕 |
| 结局 | 秘密处决（时序与"献钉"事件先后矛盾〔D-24〕） |
| 台词 | "我唯一的罪行，就是太过严肃地对待元帅的每一句话，太过真诚地执行国家的每一项规定。" |
| 薄点 | 他以为荒诞能救人。**荒诞只证明制度的荒诞，不改变制度。** |
| 写作要点 | 他的每一场戏都要"完全正确"：遵守所有规定，说所有该说的话，而这些"正确"合起来就是一场审判。 |

## P-11 钟卫

| 项 | 内容 |
| --- | --- |
| 身份 | 《新民社》记者 |
| 功能 | 双线叙事中"官方口径"的人形载体：他写的每一篇报道，都与读者刚读到的真相相反 |
