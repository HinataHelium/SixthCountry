## 一、科技基准（全书最需先定死的一条）

材料里同时出现：骑马冷兵器、土铳、自研冲锋枪、蒸汽攻城车、铁路、广播电视、核战指挥所、国际支付网络。**这是三种时代混在一起。**〔D-16〕

本库采用**"一个时代 + 一道代差"**方案：

| 项 | 采用 | 禁用 |
| --- | --- | --- |
| 总体 | **早期工业时代**（约当现实十九世纪末至二十世纪初） | 喷气机、导弹、核武器、计算机、互联网、手机 |
| 第六国 | 滞后半个时代：骑兵仍是主力，土铳（有效齐射 10—20 米）、木轮炮车、驿站 | 后装线膛枪的普及、机械化 |
| 洋博国 | 早期工业：蒸汽机、铁路、蒸汽攻城车、后装枪、电报 | — |
| 挪称 | 更先进，但主要通过洋博国间接投射力量 | — |
| 第六国自研 | **冲锋枪**（GE 中后期定型，本库暂记为 GE 二十四年前后，待定）——这是全书唯一的"技术奇迹"，必须有代价 | — |

**改写清单**（原稿中以下说法需替换）：

| 原文 | 改为 |

## 二、两场战争

### 第一次对洋博战争（GE 元年—三年）：干涉与击退

| 项 | 内容 |
| --- | --- |
| 起因 | 革命成功，洋博国的驻军权、经济特权、代理人全部作废；同时惧怕"升力"思想外溢 |
| 形态 | 洋博国以"护侨""平乱"名义出兵；蒸汽攻城车 + 铁路运兵，正面推进 |
| 第六国战法 | **山地游击战**：坚壁清野、破袭环线铁路、围点打援、夜袭、全民皆兵 |
| 结果 | 洋博国内厌战 + 挪称施压 → 停战。和约：洋博就玷污惨案道歉、撤军拆设施、废不平等条约、第六国**放弃赔款** |
| 后果 | 余亢威望登顶；康慨日后斥之"书生的仁"——"我们流血换来的胜利，为何如此廉价？" |

### 第二次对洋博战争＝斯巴统一战争（GE 二十六年—二十八年）

| 项 | 内容 |
| --- | --- |
| 名义 | "斯巴民族统一战争"——同源民族，理应一国 |
| 实质 | 转移国内矛盾 + 掠夺资源 + 造神 |
| 宣传 | 打"洋博卖国权贵"，不打"洋博人民"；称对方政权是"背叛斯巴族的傀儡" |
| 战法 | 康慨式：优势火力 + 人海 + 不计伤亡；惨胜 |
| 结果 | 吞并洋博国；故地设"洋博特别治安区"；康慨自封**大元帅**；控制大陆三成领土 |
| 战后处置 | 三期消化：过渡期（0—6 月，软禁洋博王、赐"安乐公"虚衔、中层留用掺沙子）→ 消化期（6 月—3 年，换法、换币、换语、拆军）→ 融合期（3 年后，移民、授"新第六国人"身份） |

## 三、两套军制对照

| | 人民革命军（余亢） | 国家武装力量（康慨） |
| --- | --- | --- |
| 名称 | 人民革命军 | 国家武装力量（自称"人民解放军"） |
| 军衔 | **无军衔**：总指挥／指挥／支队指挥／队长／战士 | 大元帅—元帅—将官—校官—尉官—准尉—军士长 |
| 军服 | 官兵一致，无肩章领花 | 肩章、勋章、绶带，极尽奢华 |
| 政委 | 有，且**有最终决定权**，可否决军事方案 | 有，但首要任务是监视思想、效忠个人 |
| 士兵委员会 | 有，士兵选举产生，民主监督主官 | 无 |
| 武装结构 | **三结合**：主力兵团（规模被有意控制）／地方部队／民兵全民自卫队 | **三层同心圆**：禁卫军（教导旅）／嫡系野战军／杂牌军与边防军 |
| 后勤 | 人民供养（根据地直接送粮）+ 作战间隙生产自给 | 国库 + 掠夺 + 财阀承包 |
| 指挥 | 逐级，主官与政委双长制 | 康慨可**越级直指最基层**；重要军情直送本人 |
| 特务 | 无（禁秘密警察） | 工农会特工渗透至**连级**，与主官平行，有最终否决权，可秘密处决 |
| 晋升 | 战功、群众评议 | 对康慨个人的忠诚；告密、镇压残酷、参与个人崇拜 |
| 一句话 | "官兵一致，所以能打" | "忠诚第一，所以能压" |

### 关键编制

- **总指挥**：全军最高军事首长，战时由革命委员会推举，通常由赠军担任；胜利后应即取消——但是没有人取消它。〔D-17〕
- **教导旅**：完全由孤儿培养的禁卫军，只对康慨一人忠诚。**这是全书最恐怖的一支部队**：他们没有父母，只有元帅。
- **工人纠察队**：工农会的武装，不属于军队，不受军法约束。
- **节度使**：康慨朝行省军政合一的长官，直对康慨负责——军阀制的复活。

## 四、战术与战场

### 第六国的"山林之主"战法（余亢时期定型）

1. **地形即武器**：不守城，守山口；不在平地列阵，在林中设伏。
2. **破袭**：专打铁路、桥梁（孔桥）、辎重。洋博国的钢铁巨兽离了铁路就是废铁。
3. **围点打援**：围一个据点，打来援的部队。
4. **全民皆兵**：每个村子都是补给点、情报点、撤退点。敌人在占领区找不到"前线"。
5. **以时间换空间**：不怕丢城，只怕丢人。

### 康慨的"体系瘫痪战"（GE26—28）

- 不追求击溃敌军主力，追求**打掉对方的补给、指挥、通信、意志**。
- 用宣传配合军事：先打"卖国权贵"，再打"人民"，让对方的士兵不知道自己为谁而战。
- 代价：伤亡极高，战后一代人缺失。这是他"惨胜"的真实含义。

## 五、军与政的三条铁律（写作用）

1. **谁发军饷，军队听谁的**。朵柔用国库，余亢用人民，康慨用财阀与掠夺——三种军饷，三种忠诚。
2. **军衔是政治语言**。余亢取消军衔，是因为军衔会造出"另一个等级社会"；康慨恢复并加码军衔，是因为他需要一支"用勋章换忠诚"的军队。
3. **"党指挥枪"与"枪指挥党"只差一步**：当党主席同时是元帅，这句话就反过来了。
