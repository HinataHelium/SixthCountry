# 00 · 使用说明与正典规则

本文件是整套设定库的**宪法**。写作、续写、改设定，先看这五条。

---

## 一、五条铁律

1. **只有 `docs/` 是正典。** 原始讨论稿（`sources/`）保留一切可能的说法，互相矛盾是常态，不能直接引用。
2. **专名只认 [11-专名表](11-专名表.md)。** 表里标「误写」的字形，任何文档、正文、乃至聊天里都不再使用。
3. **设定分三级**（见第二节）。写正文时，`[待定]` 的内容要么回避，要么按「建议」写并在提交信息里说明。
4. **冲突不靠猜，靠裁定。** 发现两份文档打架：先记入 [99-待决议题](99-待决议题.md)，等作者定；定了就写进 `decisions/`，再回改文档。**不得在正文里"随手统一"。**
5. **正文不产出新设定。** 写到需要新设定的地方，先补 `docs/`，再写正文。正文永远只是设定的一个投影。

## 二、标记约定

| 标记 | 含义 | 用法 |
| --- | --- | --- |
| `[定]` | 作者已确认或材料多处一致，可直接写 | 默认状态，正文可自由使用 |
| `[待定]` | 材料有两种以上互斥说法，未裁定 | 正文回避，或写成模糊表述 |
| `[建议]` | 整理者推断/补全，未经作者确认 | 只能用作文档内部一致性需要，**不得进正文** |
| `〔D07〕` | 关联 `99-待决议题` 第 07 条 | 追责用 |

禁止写法：`待定？`、`存疑`、`可能吧`——一律改成上表四种之一。

## 三、编号体系

跨文档引用一律用编号，不用全名（全名会变，编号不变）。

| 前缀 | 对象 | 例 |
| --- | --- | --- |
| `P` | 人物 | P-01 余亢 |
| `G` | 地理实体（国/地/城/设施） | G-01 斯巴大陆 |
| `O` | 组织、机构、党派、军队 | O-01 人民党 |
| `E` | 事件 | E-01 玷污惨案 |
| `B` | 书籍、报刊、文件 | B-01 《升力》 |
| `T` | 制度、礼仪、术语、罪名 | T-01 生产总额 |
| `D` | 待决议题 | D-01 |
| `A` | 已裁定事项（记在 `decisions/`） | A-01 |

编号一旦分配，**永不复用、永不改号**；人物改名只改 `11-专名表` 里的「正名」栏。

## 四、纪年写法

- 文档内一律写：**事件名（纪年）**，例：`玷污惨案（光荣纪元前五年）`。
- 需要精确日期时写：`（朵柔四十一年·大末祭后第三日）`。
- 纪元换算、三套纪年的并行关系，只认 [03-纪年与历法](03-纪年与历法.md)。
- **正文中的纪年口径由叙述者决定**，不由设定决定：官方史书线用官纪年，私人手稿线用私纪年，这两者的错位本身就是叙事装置（见 [14-叙事工程](14-叙事工程.md)）。

## 五、文档地图与写作动线

```
要写一场戏
  ├─ 查时间    → 02-编年史 / 03-纪年与历法
  ├─ 查地点    → 01-世界与地理
  ├─ 查谁能拍板 → 04-政体与权力结构
  ├─ 查暴力    → 05-军事 / 06-绩效制度与法律
  ├─ 查日常    → 07-社会、日常与语言（配给、教育、告密、光荣体）
  ├─ 查仪式    → 08-受祭与意识形态
  ├─ 查钱      → 09-经济、财阀与对外关系
  ├─ 查人      → 10-人物志
  ├─ 查怎么说  → 13-话语样本与文体
  └─ 查"这东西叫什么" → 11-专名表（最后一道关）
```

## 六、文档之间的硬约束

整理时做过的、必须保持一致的十条"接口"：

1. 首都只有一个：**将台城**（朵柔称"将台"，康慨改"将台直隶市"）。`空力府` 是政权名，不是地名。〔D-03〕
2. 政权序列只有三棒：**朵柔王朝 → 空力府（余亢）→ 康慨政权**，中间没有第四棒。
3. 党只有两个真身：**人民党**（余亢创）与**第六劳动党**（工农会改组，康慨的党）。人民党被"合并"而非"改名"。
4. 纪元只有三套：**朵柔历 / 人民纪年 / 慷慨年号**，"光荣纪元"是史书统称，不是第三套。〔D-04〕
5. 书只有两本：**《升力》**（余亢原著）与**《升命力》**（康慨钦定修订本）。二者不是同书异名。
6. 特务机关只有一个：**工农会**（全称"工农联合会"），既是群众团体又是秘密警察，双重身份是其本质。
7. 一次惨案：**玷污惨案**（又名马体克惨案）。"马体克"是地名，"玷污"是史家定名。
8. 一个人：**康慨**，字面无分隔符。〔D-01〕
9. 一场战争：**斯巴统一战争**（对洋博国），康慨以"民族统一"包装，实质吞并。
10. 一位女王：**朵柔一世**，女身，称"女王"，不称"国王"。

> 以上十条若被裁定推翻，须同步修改本文件、`11-专名表`、`99-待决议题` 三处。

## 七、版本与提交

- 改专名 → 一次提交，提交信息写「改名：X→Y（A-编号）」。
- 补设定 → 一次提交，写「补：……（文档名）」。
- 裁定 → 一次提交，写「裁定：D-编号=选项」。
- 禁止把"改名 + 补设定 + 改正文"混在一次提交里。
