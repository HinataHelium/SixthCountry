# 06 · 绩效制度与法律

> 朵柔朝用法律管**身体**，康慨朝用法律管**念头**，余亢朝试着用法律管**权力**。
> 三代法，三种对象。这就是全书的法律史。

---

## 一、朵柔朝：把人的价值换算成一个数

### T-01 生产总额

- 每个臣民出生即立**个人绩效账户**，终身为"提升帝国生产总额"而奋斗。
- 核算范围：物质生产、劳务提供、技术创新、**生育合格后代**。
- 家庭连带：一户总额未达标，**全户连坐清偿**。
- 结论条文：**"绩效乃公民唯一存在价值及权利之唯一依据。"**

### 《绩效法典》六卷

| 卷 | 名称 | 要害 |
| --- | --- | --- |
| 一 | 绩效基石法 | 出生即开户；家庭连坐 |
| 二 | 社会分级与权利法 | 甲乙丙丁戊五等；居住、交通、医疗、婚姻随等级 |
| 三 | 绩效审判法 | 无原告、报表为唯一证据、只判"有效/无效" |
| 四 | 受祭仪典法 | 祭祀改成考核（见 08） |
| 五 | 生育与教育绩效法 | 生育配额；父母等级决定子女起跑线 |
| 六 | 绩效特别区法 | 贵族看治理效率；边远地区"定额上缴，不足补足" |

**立法宗旨**（原文）："为昭彰天恩，明赏罚，定秩序，促生产，特立此法。万物皆可量，绩效即天命。"

### 五等

| 等 | 名 | 配给 | 教育 | 其他 |
| --- | --- | --- | --- | --- |
| 甲 | 卓越 | 优渥 | 高级 | 仕途优先 |
| 乙 | 优良 | 标准 | 基本 | — |
| 丙 | 达标 | 生存 | 有限 | 子女可入学 |
| 丁 | 不足 | 剥夺燃料、医药 | 子女无权入学 | — |
| 戊 | 严重不足 | 全部剥夺 | — | 强制送入绩效矫正营 |

> 评级精确到"丙下"。**一个"下"字，决定一家人的冬天有没有煤。**

### 法殿（官方名：生产总额裁定院）

| 要素 | 规定 |
| --- | --- |
| 隶属 | 直属中央生产计划委员会，对女王负责 |
| 启动 | **不需要原告**。地区绩效官按季度报表自动提交未达标名单 |
| 证据 | **唯一证据是官方绩效报表**；天灾、疾病不予采纳，除非郡府灾异鉴定司出具文书 |
| 唯一可接受的抗辩 | "数据录入错误" |
| 审判者 | 技术官僚"裁定官"（不是法官） |
| 判决 | 只判两种：**定额未遂** → 绩效矫正（效率提升营，营内双倍绩效分）；**持续性生产失效** → 死刑或终身苦役，家属打入负资产、连坐清偿 |
| 口号 | "公正即效率，效率即生命" |
| 建筑 | 极简、冷硬、无窗；庭中立"效率女神"像，一手天平、一手计算器 |

### 罪名表

- 轻度绩效过失（首次或轻微不达标）→ 警告、扣下期基础额度
- 绩效不遂罪（持续不达标）→ 强制劳役、财产充公
- 绩效叛乱罪（恶意抵制、伪造数据）→ 流放、苦役乃至死刑
- 附加恶名：懈怠者、智力残疾、天祭之弃（被受祭公开剔除者）
- "恩赏"条款：**揭发他人绩效舞弊者，可获额度奖励**

### 样本：裁定书 丙酉字第七三一号

> 事由：河间省糠秕郡黑水村，户主石老四，家庭编号七六。核定谷物四百斤，申报一百九十斤，另以劳役折三十斤，差额一百八十斤。
> 抗辩：户主称其妻久病，其子石根年十六，力不能及。
> 灾异鉴定：郡府灾异鉴定司未出具文书，不予采纳。
> 裁定：定额未遂，成立。户降丙下，剥夺下季种子、燃料配额；子石根，年十六，送绩效矫正营，营内双倍绩效分。
> ——裁定官（署名处为空白）

> 写作用：这份文书里没有一个"恶人"，只有一个签名空白。**制度的恐怖在于它不需要作者。**

### 惩罚的另一面

- 朵柔朝对不达标者的"教育"是**公开羞辱 + 强制劳动**。
- 康慨朝把"游街"写进了条例（胸前挂"智力残疾"木牌、民众掷番茄），但**从未真正执行**——他要的是让条例存在，不是让人游街。这是一种更省力的恐怖：**纸面上的酷刑，比执行中的酷刑更便宜。**

## 二、空力府：试着用法律管住权力

| 制度 | 内容 |
| --- | --- |
| 《人民权利总章》 | 废除"生产总额定死生"；生存权、居住权、教育权与绩效脱钩 |
| 公民警务委员会 | 执法权由公民让渡，**由各级人大产生并对其负责**；预算与首长任命须人大批准 |
| 程序保障 | 权限法定、禁法外行刑与秘密拘捕、**非法证据排除**、独立司法审查、公民监督团 |
| 司法委员会 | 法官由专业机构推荐、代表大会任命，独立审判 |
| 宪法委员会 | 法学家、哲学家与卸任代表组成，行合宪性审查 |
| 国家监察委员会 | 可监督**包括最高领导人在内**的一切公职人员（仅有调查权，无逮捕权） |
| 真相与和解委员会 | 公布朵柔王朝罪行，**也公布革命自身的错误** |

- 空缺：**没有秘密警察**。余亢明确拒绝设立。
- 后果：面对康慨的工农会，空力府**没有任何合法的暴力可用**。它只有辩论、程序和道德。

> 这是全书最大的悲剧装置：**最好的法律，遇上一个不需要法律的对手。**

## 三、康慨朝：把罪名写进人的脑子里

### T-05 惰念罪

| 项 | 内容 |
| --- | --- |
| 字义 | "惰"＝思想的懈怠、精神的停滞、进取心的丧失；"念"＝念头、潜意识 |
| 本质 | 把一切不积极、不狂热、不盲从的**独立思维**，定为可铲除的罪 |
| 定罪标准 | 模糊到无限：听讲话神情不够激动、未及时鼓掌、质疑《升力》、传唱"低沉"民歌、对指标作悲观估计、与"思想不纯"地区的人交往过密；日记流露彷徨、夫妻私语抱怨被邻居举报、醉后牢骚 |
| 程序 | 工农会下属**人民思想法庭**审理；**不公开**；不需物证；由**思想鉴定官**依言论、文章、面相、梦境记录出具"具有惰念倾向"的鉴定报告；邻居、同事、家人的举报信为最佳证据 |
| 三级惩罚 | 初级：思想净化营（背语录）；中级：特殊定居点（高强度劳动改造）；高级：公开审判，定"帝国主义惰念间谍"，处死 |
| 宣传话术 | "清除'惰念'，不是迫害，而是最高形式的'精神防疫'，是对民族未来最深沉的爱护。" |

### 其他罪名

| 罪名 | 用途 |
| --- | --- |
| 解构罪（全称：分解国家同一性、发展地下虚无主义组织罪） | 专治"用荒谬暴露荒谬"的人（李惘案） |
| 背叛革命 / 分裂党 / 洋博国间谍 | 政治清洗通用 |
| 怀恋前朝、图谋不轨 | 私用旧历、私藏旧物 |
| 扰乱经济秩序 | 清除国企竞争者 |
| 顽固派 / 投降派 / 抗拒统一 / 怀念旧政权 | 吞并洋博后的整肃用语 |

### 司法现状

- 法院、检察院**沦为橡皮图章**，为工农会的非法行为提供"合法"外衣。
- 工农会权力：任意逮捕、秘密审判、无限期羁押、酷刑逼供，**超越一切法律与司法机关**。
- 象征：**夜晚的敲门声**。
- "人民审判"：游街、公审大会、群众举手定罪——法律被替换为仪式。

| | 朵柔 | 余亢 | 康慨 |

## 五、三份可以反复用的"法律场景"

1. **一份报表**：某人多报了十斤粮，救活一家，也害死一家。
2. **一次鉴定**：思想鉴定官凭"面相"写下结论，被告在旁听席上认出鉴定官是自己从前的学生。
3. **一份签名**：大赦令上需要康慨的签名，而签名处永远空白——因为法殿的裁定官从来不签名（呼应朵柔朝的裁定书）。
