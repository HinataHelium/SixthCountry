## 二、朵柔王朝：一台榨取机器

### 结构

```
                    朵柔一世（女王·立法·行政·司法·军权）
                              │
        ┌─────────────────────┼─────────────────────┐
   中央生产计划委员会      大将军府              法殿（生产总额裁定院）
   （定指标）              （镇反、平乱）          （判"有效／无效"）
        │                                            │
   九生产区 → 郡 → 县 → 里                       郡府灾异鉴定司
   （绩效官、里正、告密人）                      （唯一可开天灾证明的机关）
```

### 要点

- **不是官僚制，是考核制**。女王不需要忠臣，只需要数字；官员的忠诚由"辖区总额增长"来证明。
- **五等**：甲（卓越）、乙（优良）、丙（达标）、丁（不足）、戊（严重不足）。配给、教育、医疗、居住、婚姻申请全部随等级浮动（详见 06）。
- **连坐**：一户未达标，全户清偿。子入矫正营，户降等，种子与燃料配额取消。
- **贵族**：有"效忠折算"，绩效指标与治理效率、忠诚度挂钩——所以贵族永远比平民容易"达标"，这是制度性的不公，也是革命的燃料。
- **大将军**：凌号即此职，掌兵又掌商，是王朝自己养出来的掘墓人。
- **种姓外皮**：以"绩效世袭"替代血缘种姓，分新四民——皇族与功勋贵族／士族绩效官僚／生产民／绩效不达标者（详见 07）。

> 写朵柔朝的诀窍：**没有坏人，只有报表。** 每一个施暴者都在完成指标。

## 三、空力府：一部"太精密所以易碎"的机器

### 双轨：党与政府

```
        全国人民代表大会（最高国家权力机关·代表由基层直选·可随时罢免）
              │  授权                        │ 监督、质询、罢免
     ┌────────┴────────┐                    │
  人民党              国务院（总理、各部）    │
  ├ 全国代表大会        └ 地方政府            │
  ├ 中央委员会（无立法权，仅提议案）          │
  ├ 政治局 → 常委会（集体领导，协调员）       │
  └ 书记处（组织部·宣传部·军事部）            │
              │                               │
        宪法委员会（合宪性审查）  司法委员会（独立审判）
        国家监察委员会（可监督最高领导人）
```

### 权力五原则

1. **主权在民**：一切权力自下而上；基层大会可直接选举并随时罢免代表。
2. **不是党领导人大，是人大授权党去领导**。党是"先锋队"，是人民的向导，不是主人。
3. **党的终局是消亡**：《升力》明写——社会自治实现之日，党自行解散。这是余亢全部悲剧的伏笔。
4. **四大重置机制**：定期选举（同一职务连任不超两届）／随时罢免／全民公投／抽签（基层议会与陪审团部分成员抽签产生）。
5. **非党员可任政府高官**，宪法与选举法明定不分党派；但"原则上"不得进入党中央。（这条"原则上"，就是康慨的突破口，见 〔D-13〕。）

### 谁能否决谁

| 机关 | 能不能否决 | 实际后果 |
| --- | --- | --- |
| 全国人大 | 能否决党中央与国务院 | 但代表是兼职的、没有专职经费、休会即散 |
| 党中央 | 不能立法，只能提议案 | 一旦掌握提名权与信息，就实质支配人大 |
| 常委会 | 只是协调员，紧急处置须事后报备追认 | 危机时刻"事后追认"变成"既成事实" |
| 宪法委员会 | 能判违宪 | 但它由卸任代表与学者组成，没有执行力量 |
| 国家监察委员会 | 能监督最高领导人 | 它只有调查权，没有逮捕权 |

> **空力府的死因写在这张表里**：每一个"能管住"的机关，都缺一样东西——时间、钱、枪。而康慨三样都有。

### 官僚的两种人（写作可用）

- **政务官**：人民党委派，管方向，随时可撤。
- **事务官**：考试录用，管执行，自以为中立，实际是"政策被重新加工"的地方。
- 康慨夺权时，正是把这两层**焊成一层**：事务官也被要求"政治可靠"。

## 四、康慨政权：一座三层同心圆

### 结构

```
                      康慨
        （党主席 · 大元帅 · 国家主席 · 国父 · 导师
           · 慈父 · 新共产主义总设计师）
                            │
        ┌───────────────────┼───────────────────┐
   党（第六劳动党）      国（国务院/人大）      军（大元帅府）
        │                   │                   │
   政治局常委会        橡皮图章式人大        禁卫军（教导旅）
   书记处              国务院                嫡系野战军
   各级党委            节度使（行省军政合一）  杂牌军与边防军
        └───────────────────┼───────────────────┘
                            │
                    工农会（工农联合会）
              群众团体 + 秘密警察 + 第四权力
              总会长 → 地方总会长 → 分会（垂直单线）
              自收会费、自有武装（工人纠察队）、自有宣传
```

### 六条运作法则

1. **三位一体**：党主席（党权）＋大元帅（军权）＋国家主席（法权），闭合成"党即军即国"。
2. **会议即仪式**：党代会五年一次，中央全会一年一至两次，政治局一月一次，常委会一周一次，书记处一周两三次，军委不定期——**全部功能是"确认与背书"，不是决策**。
3. **常委会四用**：内部维稳、执行意志、**分锅背责**、最高咨询。
4. **工农会是第四权力**：与党、政、军平行，只对康慨一人负责，可越级直达连级，可秘密处决。
5. **形式多党制**：第六劳动党 + 人民进步党 + 国家复兴同盟 + 工农联盟。党纲与主要政策须经"宪法委员会／民族和解委员会"审核；反对党领袖多为秘密党员。
6. **受控反对**：可以批评"现象"，绝不能质疑"根本"。禁区是：康慨本人、一党专政的合法性、康慨思想、历史定论。批评必须走"群众来信"办公室或内部参考刊物，且结局预设为"领袖明察、有则改之"。

### 康慨的职衔阶梯（写文件时必须分清）

| 阶段 | 正式称谓 |
| --- | --- |
| 起义—建国初 | 内务委员（社会治安委员会） |
| 掌权期 | 工农会总干事 / 政治保卫总局局长〔D-14〕 |
| 入最高层 | 党中央政治局常委、特别事务委员会主席 |
| GE18 起 | 党主席、国家元首，授**元帅** |
| GE26 起 | 自封**大元帅**（终身、唯一） |
| 全盛期固定全称 | "我们伟大、光荣、正确的导师、领袖、元帅和国父，第六国人民的慈父，新共产主义的总设计师康慨同志" |

> 称号的四个功能：心理威慑（长到念不完）、合法性建构（重复即事实）、信息筛选（引用是否完整＝站队测试）、仪式化服从。详见 [13](13-话语样本与文体.md)。

## 五、三种"合法性"的对照（写作母题）

| | 靠什么被承认 | 最怕什么 | 死法 |
| --- | --- | --- | --- |
| 朵柔 | **暴力**（恐惧） | 数字不达标 | 被更强的暴力推翻 |
| 余亢 | **观念**（信仰） | 信仰被证明无用 | 被自己容忍的暴力反噬 |
| 康慨 | **垄断**（唯一的承认来源） | 自己死掉 | 人死则系统崩（无继承人） |

> 三代人回答同一个问题：**凭什么你说了算？** 三种答案，三种死法。这是全书的隐线。
