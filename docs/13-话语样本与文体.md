# 13 · 话语样本与文体

> 本书的"文风"不是一种，是**五种互相打架的声音**。
> 读者靠语体的切换来辨认：现在说话的是谁——国家、报纸、学者，还是一个人。

---

## 一、五种语体

| 语体 | 谁在用 | 特征 | 例句 |
| --- | --- | --- | --- |
| **通志体** | 官修史书 | 文言骨架、四字句、志后赞曰翻刀 | "制虽屡易，其核心未尝变也：皆以江山为棋盘，以万民为筹码。" |
| **新民社体** | 官方新闻 | 全称、排比、最高级形容词、群众反响 | "倍感振奋、备受鼓舞、信心满怀" |
| **公文/法典体** | 政府、法庭 | 无主语、条款化、"不予采纳" | "天灾、疾病等理由，不予采纳。" |
| **余亢体** | 私人文章、演讲 | 短句、追问、克制的愤怒 | "没有民主监督的集中，必然滑向独断专行。" |
| **手稿体** | 私人日记、书信 | 口语、省略、日期错乱、写到一半停笔 | "今年不是这个年号。" |

**写法铁律**：一段之内不许混两种语体。要换，就换行、换出处标注、换字体（排版上）。

## 二、《再版说明》（卷首，全文）

> 这是全书正文的第一件文件。它是**宣战书**，也是**墓志铭**。

```
《第六国兴衰录》再版说明

新民社出版局 编

在波澜壮阔的伟大时代洪流中，在康慨元帅光辉思想的指引下，我国文艺出版事业
迎来了新的繁荣高峰。为响应广大读者对更高质量精神文化产品的迫切需求，应出版
总署统一规划，新民社出版局现隆重推出经典史话作品《第六国兴衰录》之权威修订版。

本书初版发行后，在读者中引起了广泛而热烈的积极反响，为人民群众学习历史、
洞察世情提供了宝贵的精神食粮。然，为更全面、更深刻、更精准地展现那段错综复
杂、跌宕起伏的历史时期，揭示其内在的发展规律与历史必然性，使之更符合新时代
的宣传口径与教育要求，我局在上级主管部门的亲切关怀与直接领导下，组织权威专
家与资深编辑，对原书结构进行了必要的、科学的、严谨的优化与重塑。

此次修订工作，是本着对历史负责、对读者负责、对事业负责的态度进行的一次精
益求精的完善。修订版进一步突出了历史的主线脉络，强化了核心思想的引领作用，
优化了叙事逻辑的层次性与连贯性，使其更有利于引导读者正确理解历史的本质与全
貌，从而更深刻地领悟当前来之不易的幸福生活，以及领导我们事业从胜利走向新的
胜利的核心力量之伟大与正确。

我们坚信，此次修订将使本书的思想性、艺术性与可读性提升到一个新的高度，更
好地服务于全党全国工作大局，更好地为全面建设社会主义现代化强国凝聚磅礴精神
力量。

新民社出版局
光荣纪元X年X月X日
```

**三个可用的破绽**（写评论/私史时点出来）：

1. 全文没有一处提到"修订了什么"。只说"优化与重塑"。
2. "更符合新时代的宣传口径"——这一句把修订的性质说漏了。
3. 署"光荣纪元"而非"慷慨年号"——**连出版局都在用两套时间**。〔D-04〕

## 三、《严正声明》（卷首之二，全文见 `sources/原始素材/01-再版说明.txt`）

要点与功能：

- "一切国家、地域、机构、组织、事件、人物……均为凭空虚构"——**在小说内部，这是一份"此地无银"的文件**。
- "坚决反对并拒绝任何试图将文艺作品与现实进行简单比附、恶意勾连的错误倾向"——越是声明，越像招供。
- 写法建议：全文照录，不加一字评论。让读者自己发笑，然后发冷。

## 四、领袖称号

### 全称（必须一字不差）

> **我们伟大、光荣、正确的导师、领袖、元帅和国父，第六国人民的慈父，新共产主义的总设计师康慨同志**

### 构成与功能

| 词 | 功能 | 潜台词 |
| --- | --- | --- |
| 我们 | 表面平等，实为"拥有者"的口吻 | 你们是他的 |
| 伟大、光荣、正确 | 三位一体的神格化 | 不可质疑 |
| 导师 | 思想权威 | 你要学习 |
| 领袖 | 政治权威 | 你要跟随 |
| 元帅 | 暴力垄断 | 反抗的后果 |
| 国父 | 与国家绑定 | 不可挑战 |
| 第六国人民的慈父 | 情感绑架 | 你要孝忠 |
| 新共产主义的总设计师 | 理论合法性 | 他是路线的来源 |
| 同志 | 虚伪的谦逊 | 神仍与民同在 |

### 使用规则

- 首次出现用全称；其后可称"康慨元帅""元帅"；**严禁直呼其名**。
- 文件、报道、教材中的省略＝政治站队失误，可被举报（情节可用）。
- 口头呼喊："康慨元帅万岁""祝元帅万寿无疆"。

## 五、新民社体样本

### 5.1 现场报道（记者 钟卫）

```
【本报讯】昨日，在我市开展例行治安巡查期间，发生一起骇人听闻的敌特分子
企图暴力袭击我军战士事件。我执勤战士临危不惧、果断处置，当场将该名凶徒
制服，有力地维护了社会治安秩序，保障了人民群众的生命财产安全。

经初步核查，该男子系社会闲散人员，曾有多次小偷小摸、酗酒闹事的不良记录，
且与境外势力有可疑接触。目前，案件正在进一步审理中。

本报评论员指出：境内外敌对势力亡我之心不死，广大市民务必提高警惕，
凡发现可疑人员、可疑言行，应立即向工农会或公安机关举报……
```

**四步定式**：颠倒因果 → 污名化受害者 → 英雄化施暴者 → 升华为敌我矛盾并动员举报。

### 5.2 社论体

```
论受祭之复兴

一、元帅恢复了古老的受祭，也恢复了第六国的灵魂。

   无第六国，则无受祭。此非一人之荣，乃万民之幸。
```

### 5.3 新年贺词通稿（模板，节录）

```
电头：新民社将台城1月1日电（记者 钟卫）
标题：【领航新时代 奋进新征程】康慨元帅发表新年贺词 擘画光荣国伟大复兴宏伟蓝图
副标题：全国各族人民满怀豪情聆听领袖教诲 纷纷表示要紧密团结在元帅周围
        为全面建成强国伟业不懈奋斗

本报讯 新元肇启，万象更新。在这普天同庆的美好时刻，我们伟大的导师、领袖、
元帅和国父，光荣国人民的慈父，新共产主义的总设计师康慨同志，于今晚7时通过
新民之声广播电台向全国各族人民及海外侨胞发表了充满力量、高瞻远瞩的新年贺词。

（固定段落：代表党中央、国务委员会、中央军事委员会，并以他个人的名义，
向全国各族工人、农民、知识分子、干部和各界人士，向人民解放军指战员、
武警官兵和公安干警，致以新年的祝福。）

——我们的经济实力实现历史性跨越。在元帅亲自擘画、亲自指挥下……
——我们的社会大局保持和谐稳定。元帅始终心系人民福祉……
——我们的国际地位空前提升。在元帅纵横捭阖、亲自运筹下……

康慨元帅强调，这些成就的取得，最根本的原因在于全党全国各族人民坚定不移地
遵循他的思想，贯彻他的指示，执行他的路线。

（固定结尾：热烈反响、强烈共鸣、倍感振奋、备受鼓舞、信心满怀、
以优异成绩向他献礼！）
```

**仿写要点**：主语永远是"元帅"；功劳归他，困难归"复杂形势"；每个段落都要出现"在……领导下"。

## 六、公文与法庭语体

### 6.1 裁定书（朵柔朝，见 06 全文）

特征：无主语、条款化、只引报表、"不予采纳"、署名处空白。

### 6.2 判决公告（康慨朝）

```
第六国最高人民法院 公告

罪犯李惘，男，年三十七，原系将台城第三区供热办公室办事员。
该犯长期散布荒谬言论，以"过度执行"为名，行"解构"之实，煽惑群众，
妄图分解国家同一性，发展地下虚无主义组织，罪行极其严重，民愤极大。
经本院依法审理，该犯对所犯罪行供认不讳。
依照《第六国刑法》及《惩治思想犯罪条例》之规定，判处罪犯李惘死刑，
剥夺政治权利终身。
特此公告。

第六国最高人民法院
慷慨七年X月X日
```

**注**：正史里这份公告是真的；野史里，李惘在庭上说了那句"我唯一的罪行，就是太过严肃地对待元帅的每一句话"——而这句话没有出现在任何公告里。
