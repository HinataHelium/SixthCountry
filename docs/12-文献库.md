## 二、重点书目卡

### B-01 《升力》

| 项 | 内容 |
| --- | --- |
| 著者 | 余亢 |
| 成书 | 朵柔三十一年（GE 前十五年）前后，手稿秘密流传；GE 后刊行 |
| 题解 | "升"＝人的内在觉醒；"力"＝自由人的联合。合起来：**人靠觉醒与联合，向上生长** |
| 结构（初稿本） | 序章·我们的困境／卷一·基石：何为"升"／卷二·脉络：何为"力"／卷三·践行：如何实现"升力"／卷四·愿景：升力之后的世界／附录·核心概念释义 |
| 结构（修订本，即后来刊行本） | 序章·双重的枷锁／卷一·觉醒／卷二·力量／卷三·道路／卷四·愿景 |
| 关键主张 | 历史是人民创造的；党是先锋队、终将消亡；国家职能最终融化于自由人联合体；"计时之权当归于民" |
| 命运 | 原为启蒙之书 → 被康的慨钦定为"宝典"、语录即最高法律 → 宗教化后改名《升命力》 |
| 残卷 | 手稿残卷传说藏于秘境图书馆 |
| 写作价值 | 全书最重要的一件"档案"：**同一本书，在三个时代被读出三个意思。** |

> 引用它的时候，永远要交代"读的是哪一版"——初稿、刊行本、还是《升命力》。版本差异本身就是情节。

### B-02 《升命力》

| 项 | 内容 |
| --- | --- |
| 署名 | "集体编写"，实际由康的慨思想研究院修订 |
| 题解 | 只加一个"命"字：从"人的上升"变成"为领袖献命" |
| 手法 | 原文保留、批注篡改：在关键段落加"然而""必须指出"，把民主段落注释为"不成熟的空想" |
| 用途 | 全民必读；宗教收编后的"新圣经"；课堂、教堂、军营通用 |
| 恐怖之处 | 它没有删掉余亢的话。它让余亢**自己反对自己**。 |

## 三、报刊文体清单（写作时直接套）

| 文体 | 用途 | 模板要点 |
| --- | --- | --- |
| 社论 | 定调、定性 | 先立"敌我"，再讲"必然"，末句号召 |
| 通稿 | 领袖活动 | 电头＋全称称号＋排比＋群众反响 |
| 新年贺词 | 年度总结 | 见 13 的完整模板 |
| 现场报道 | 治安事件 | 颠倒因果→污名化受害者→英雄化施暴者→升华为敌我矛盾 |
| 国际论战 | 反击制裁 | 先否认事实，再反转指控（"你们才是……"），最后诉诸主权 |
| 讣告 | 领袖之死 | 不写死因，只写"永垂不朽" |
| 判决公告 | 公审 | 罪名＋"供认不讳"＋"群众一致要求"＋"依法" |
| 贺电 | 外交 | 称谓、祝愿、共同事业 |

> 这些文体**互相之间要能对上暗号**：同一件事，社论说"胜利"，报道说"挑衅"，贺词说"关怀"。读者把三份放在一起，才看见真相。
