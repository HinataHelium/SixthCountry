# 文献库 · 索引

本目录存放**可以原文挟带进正文的文件**。目标：每部书刊一个文件，带书目信息与"物质性"描述。

## 命名规则

```
B-01-升力.md
B-02-升命力.md
B-06-第六国通志.md
N-01-新民社社论选.md      （N = 报刊，不占 B 号）
```

## 每份文件的开头必须写

```markdown
> **编号**：B-01
> **版本**：手稿本 / 刊行本 / 慷慨朝钦定本
> **著者**：余亢
> **成书**：朵柔三十一年
> **存世**：残卷三册，缺序章
> **物质性**：毛边纸，钢笔，页边有他人铅笔批注
```
